# ПИПКА — голосовой помощник 🎲

ПИПКА слушает микрофон, просыпается на слово «ПИПКА», открывает программы, игры, сайты,
файлы и папки, отвечает на вопросы через Gemini и управляется с телефона через Telegram-бота.

## Как скачать и запустить (Windows 10/11)

**1. Установи Python 3.12 или 3.13** с сайта python.org. При установке обязательно отметь галочку **«Add python.exe to PATH»**.

**2. Скачай ПИПКУ** — один из двух способов:
- **Без гита:** на странице репозитория на GitHub нажми зелёную кнопку **Code → Download ZIP**, распакуй архив (например, на рабочий стол).
- **Через гит:** открой PowerShell и выполни
  ```
  git clone <ссылка на репозиторий>
  ```

**3. Установи библиотеки.** Открой папку ПИПКИ, в адресной строке проводника напиши `powershell` и нажми Enter. В открывшемся окне по очереди:
```
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m pip install -r requirements_voice.txt
```

**4. Собери приложение:** дважды нажми `build_exe.bat` (несколько минут, нужен интернет). Получится `dist\PIPKA\PIPKA.exe` и ярлык **PIPKA** на рабочем столе. Запускай ПИПКУ этим ярлыком.

Запустить без сборки (для проверки): `.venv\Scripts\python.exe main.py`.

**5. Первый запуск:**
- Нажми **«Включить слушание»**. Модель распознавания речи (около 45 МБ) скачается сама при первом включении.
- Для ответов на вопросы добавь ключ Gemini: ⚙ Настройки → «Ввести ключ Gemini» (см. ниже).
- Для управления с телефона включи **«Telegram-бот»** (см. ниже).
- Свои программы, которых нет в меню «Пуск», добавляй командой «запомни программу майнкрафт = C:\путь\к\программе.exe».

Ключи, токены, память и список программ хранятся только у тебя на компьютере и в репозиторий не попадают (см. `.gitignore`).

Данные готового приложения лежат в `%APPDATA%\PIPKA` (память, ключи, apps.json, aliases.json, журнал `pipka_log.txt`). Пересборка их не трогает.

## Как скачать и запустить на Mac (macOS 12 и новее)

**1. Установи Python 3.12 или 3.13** с сайта python.org (установщик для macOS). После установки дважды нажми файл **«Install Certificates.command»** в папке «Программы → Python 3.x» — без этого не будут работать интернет-функции.

**2. Скачай ПИПКУ:** на GitHub **Code → Download ZIP** и распакуй, или в Терминале:
```
git clone <ссылка на репозиторий>
```

**3. Собери приложение:** дважды нажми `build_mac.command`. Если Mac не даёт открыть файл, в Терминале перейди в папку ПИПКИ и выполни:
```
bash build_mac.command
```
Сборка ставит библиотеки и делает `dist/PIPKA.app` (несколько минут, нужен интернет). Перетащи **PIPKA.app** в «Программы».

Запустить без сборки (для проверки): `.venv/bin/python main.py`.

**4. Первый запуск и разрешения macOS:**
- Приложение не подписано Apple, поэтому первый раз открой его **правой кнопкой → Открыть → Открыть**.
- Разреши доступ к **микрофону**, когда Mac спросит (иначе ПИПКА не услышит тебя).
- Для команды «сделай скриншот» разреши **Запись экрана**: Системные настройки → Конфиденциальность и безопасность → Запись экрана → ПИПКА.
- Для «громче», «пауза», «выключи компьютер» Mac спросит разрешение управлять «System Events» / «Музыкой» — нажми «Разрешить».
- Озвучка без интернета использует голос Mac **Milena**. Если его нет: Системные настройки → Универсальный доступ → Устная речь → Системный голос → добавь русский голос.

Данные на Mac лежат в `~/Library/Application Support/PIPKA`.

**Чем Mac-версия отличается:** программы ищутся в «Программах» (`.app`), «пауза» и «следующий трек» работают для Spotify и Apple Музыки, внешние диски — в `/Volumes`, выключение — через 30 секунд с возможностью отменить. Telegram-бот, рулетка, кубик, поиск файлов, таймеры и погода работают так же, как на Windows.

## Команды
- **Программы и игры:** «открой стим», «открой майнкрафт», «открой айзек», «включи халф лайф». Игры Steam находятся сами.
- **Сайты:** «открой ютуб», «открой emaktab», «загугли погоду».
- **Файлы и папки:** «открой папку папа», «открой файл горгаз 2025», «найди файл отчёт» (покажет в папке). Числа можно говорить словами: «две тысячи двадцать пятый» = 2025. Ищет на рабочем столе, в документах, загрузках, картинках, видео, музыке и на дисках D–G.
- **Любой файл:** «открой любой реферат на рабочем столе» — случайный подходящий документ. Места: «на рабочем столе», «в загрузках», «в документах», «на диске д».
- **Закрыть:** «закрой стим», «закрой майнкрафт» (сначала вежливо, через 3 секунды — принудительно).
- **Звук и музыка:** «громче», «тише на 30», «выключи звук», «пауза», «следующий трек», «звук на максимум».
- **YouTube:** «включи на ютубе обзор майнкрафта», «найди котиков на ютубе».
- **Таймеры:** «таймер на 5 минут», «напомни через 20 минут выключить чайник», «напомни в 7:30 про школу», «какие напоминания», «отмени таймеры». Напоминание приходит звуком, голосом и в Telegram. После перезапуска ПИПКИ напоминания не сохраняются.
- **Скриншот:** «сделай скриншот» — сохраняется в «Картинки\ПИПКА скриншоты» и отправляется в Telegram.
- **Погода:** «какая погода», «погода в Москве».
- **Кубик:** «брось кубик», «что выпало». Нажми на кубик — он тоже бросается. За шестёрку +50 фишек.
- **Казино (понарошку, без денег):** плитка **🎡 Рулетка** или «открой рулетку» — окно с колесом: выбираешь ставку (10–500 или «всё») и на что ставить (красное, чёрное, чётное, нечётное, 1–18, 19–36 — ×2; зеро или число — ×36), жмёшь «Крутить». Быстро голосом: «рулетка на красное 200 фишек», «рулетка на 17». Ещё: «баланс», «подбрось монетку», «ставлю на орла 100 фишек». В начале 1000 фишек, если всё проиграл — банк даст ещё 500.
- **Прочее:** «который час», «какое сегодня число», «помощь», «выключи компьютер» (с подтверждением).
- **Память:** «запомни, что …», «что ты помнишь», «забудь всё», «очисти историю».
- **Научить слово:** «запомни, что чтим это steam» — если микрофон слышит название неправильно.
- **Своя программа:** «запомни программу майнкрафт = C:\путь\к\программе.exe».

Если сказать только «открой», ПИПКА спросит «Что открыть?» и следующую фразу примет как название.

## ИИ (Gemini)
Команды работают без ИИ. Чтобы ПИПКА отвечала на вопросы, нужен бесплатный ключ:
aistudio.google.com → Get API key → в ПИПКЕ ⚙ Настройки → «Ввести ключ Gemini».

## Telegram-бот
1. В Telegram у **@BotFather** отправь `/newbot` и получи токен.
2. В ПИПКЕ включи переключатель **«Telegram-бот»** и вставь токен.
3. В окне ПИПКИ появится код привязки из 6 цифр — отправь его своему боту.
4. Внизу в боте появятся кнопки: Steam, Minecraft, eMaktab, YouTube и другие.

Бот слушается только привязанный чат. Работает, пока компьютер включён и ПИПКА запущена.
Выключение компьютера и память с телефона отключены. Отвязать: `/unpair` или ⚙ Настройки.

## Голос
- Кнопка **«Включить слушание»** — ПИПКА постоянно ждёт слово «ПИПКА». Слово «ПИПКА» и фоновые разговоры распознаются только на компьютере (Vosk).
- **Команда после «ПИПКА»** (или по кнопке 🎤) отправляется на распознавание в Google — так точнее, и английские названия понимаются (Steam, Minecraft). Без интернета используется Vosk. Выключить: в `pipka/stt.py` поставить `ONLINE_STT = False` и пересобрать.
- Что услышал микрофон, видно в карточке слева и в журнале `pipka_log.txt` (строки «слышу:»). Если слово понимается неправильно — научи его командой «запомни, что … это …».
- Озвучка: голос Microsoft Edge (нужен интернет), без интернета — встроенный голос Windows.

## Если что-то не работает
- Открой `%APPDATA%\PIPKA\pipka_log.txt` (⚙ Настройки → «Открыть папку с данными») и пришли последние строки.
- Новый файл не находится: ⚙ Настройки → «Обновить список файлов».
- Telegram-бот молчит: проверь интернет и что переключатель «Telegram-бот» включён.
